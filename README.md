# Scotting — byscotting.com

Sitio de marca personal de Eduardo Scott. Vite + React + TypeScript + Tailwind.
Español en `/`, inglés en `/en`.

## Correr en local
    npm install
    npm run dev

## Publicar
    npm run build

Deploy en Vercel (proyecto separado del de idddeas.com).

## Formulario de contacto
Si `VITE_FORM_ENDPOINT` no está definida, el formulario abre WhatsApp con el
mensaje ya armado. Si se define, hace POST del JSON a esa URL.

## Marca
Vectores y logos en `brand/`. Guía completa en
`Documents/Scotting/SCOTTING-BRAND.md`.
